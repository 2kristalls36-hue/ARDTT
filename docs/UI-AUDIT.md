## Отложено, с причиной

- Разбиение `AdminDeployScreens.kt` по ответственности — идёт отдельным коммитом
  (чистое перемещение).
- `ArdttIpChip` в `ClientsScreen`, `ArdttCheckboxRow` в выборе серверов — после разбиения.
- Ошибки в диалогах через `isError`/`supportingText`; dirty-guard формы деплоя.
- Полная централизация статических строк admin-экранов в `*Copy`.
- Мёртвые токены `ArdttColors.Terminal*` — терминал использует цвета схемы; удалить
  после подтверждения, что они не нужны серверным лог-цветам.
