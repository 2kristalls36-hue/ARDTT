# Легенда AWDTT

## Имя

**AWDTT** читается как одно слово («а-вэ-ди-ти-ти» / «aw-dee-tee-tee»), расшифровка:

| Часть | Откуда | Что даёт продукту |
|-------|--------|-------------------|
| **A** | **Amnezia** / AmneziaWG | Прямой быстрый VPN (Path A): UDP, AmneziaWG 2.0 userspace на телефоне и `amneziawg-go` на VPS |
| **WDTT** | **W**ireGuard/RAW **D**ial via **T**URN / **T**elephony-style path | Обходной контур (Path B): сырые IP-пакеты в RTP-подобной обёртке WRAP через TURN звонка |

Итоговая формула:

> **AWDTT = Amnezia + WDTT**  
> один клиент, один ваш сервер, два независимых способа дойти до него.

Раньше репозиторий носил временное имя `nonameVPN`. Продуктовое имя зафиксировано как **AWDTT**; внутренние пути (`com.nonamevpn.app`, `/opt/nonamevpn/`) могут ещё встречаться как совместимость — это не отдельный продукт.

Знак приложения — стилизованная **A** Amnezia (белый фрагментированный глиф) на тёмно-синем круге с тонкой белой обводкой: буква «A» в имени и наследие прямого пути.

---

## Замысел одной фразой

Сделать **личный** VPN, который:

1. работает **быстро**, когда сеть до VPS нормальная (AmneziaWG);
2. **не отваливается**, когда UDP/IP до VPS режут, но ещё ходят «белые» сервисы и звонки (WDTT);
3. остаётся **self-hosted** — ключи и egress на вашей машине, а не в чужом SaaS-VPN.

---

## Два пути (легенда для пользователя)

### Path A — «Прямое» (Amnezia)

- Классический VPN-туннель на базе **AmneziaWG 2.0** (развитие WireGuard с обфускацией заголовков).
- Телефон ↔ VPS по UDP.
- Когда проходит — это основной, самый быстрый режим.
- В UI: «прямое», уведомление `AWDTT · прямое`.

### Path B — «Обход» (WDTT)

- Если прямой UDP мёртв или нестабилен, клиент поднимает **WDTT**:
  - создаётся (или берётся сохранённый) **hash звонка**;
  - `go_client` / `libclient.so` строит сессии через **TURN** (TCP), трафик выглядит как медиазвонок;
  - внутри — **RAW** IP-пакеты с AEAD (WRAP), без второго WireGuard и без DTLS;
  - на VPS их принимает **wdtt-server** (`-listen-raw`) и отдаёт в интернет (или в WARP).
- В UI: «обход», уведомление `AWDTT · обход`.

### Автовыбор

Приложение **само** зондирует сеть (интернет, «открытость», UDP до AWG, captive portal) и предлагает path.  
Можно принудительно зафиксировать «только прямое» или «только обход» в настройках.

---

## «Скрыть свой IP» (WARP) — не третий path

Галочка **не** добавляет третий способ дозвона до телефона.

- Трафик по-прежнему приходит на VPS по Path A или Path B.
- На сервере для этого `host_id` включается policy routing → **Cloudflare WARP** (`warp0`).
- Снаружи сайты видят IP WARP, а не IP VPS.
- DNS клиента идёт на шлюз туннеля (dnsmasq) / main, **не** через WARP — иначе «IP есть, сайты не открываются».

## Роли в системе (кто за что отвечает)

| Роль | Имя в стеке | Смысл в легенде |
|------|-------------|-----------------|
| Выдача профилей | `provision` | «Пропуск» пользователя: `host_id`, ключи AWG, пароль WDTT |
| Прямой вход | `direct` | Врата AmneziaWG на VPS |
| Обходной вход | `bypass` | Врата WDTT RAW после TURN |
| DNS шлюза | `dns` | Локальный резолвер на `10.8.0.1` / `10.9.0.1` |
| Маскировка выхода | `warp` | Опциональный «плащ» egress |
| Клиент | Android **AWDTT** | Один туннель VpnService, два бэкенда, soft-reconnect |

Адресация: один `host_id` → `10.8.0.{id}` (Amnezia) и `10.9.0.{id}` (WDTT) — один человек, два «портала» на сервер.

---

## Почему не «просто Amnezia» и не «просто WDTT»

- **Только Amnezia** — отлично в нормальной сети; бессильна, если UDP до вашего IP режут под корень.
- **Только WDTT** — живёт за счёт чужой TURN/API звонков; медленнее и хрупче к смене инфраструктуры; не нужен, когда прямой путь открыт.
- **AWDTT** держит оба контура в одном продукте: скорость там, где можно; обход там, где нельзя; один профиль, один UX.

## Символика интерфейса

- Название на главном экране и в лаунчере: **AWDTT**.
- Иконка: круглая **A** на тёмно-синем — отсылка к Amnezia-половине имени; WDTT «спрятан» в обходном path, как запасной контур.
- Уведомления: `AWDTT · прямое` / `AWDTT · обход` — всегда видно, каким путём вы сейчас идёте.

## Происхождение кода (честная атрибуция)

AWDTT — **комбинированное** самохостовое произведение, не форк «официальной Amnezia» как единого приложения и не рескин WDTT:

- Path A и серверный AWG — линии [AmneziaWG](https://github.com/amnezia-vpn/amneziawg-android) / amneziawg-go (в основном Apache-2.0).
- Path B — линии [WDTT](https://github.com/amurcanov/proxy-turn-vk-android) (GPL-3.0): `android/go_client`, `server/bypass/wdtt-server`.
- Общая упаковка, UX, provision, DNS, WARP-policy, soft-reconnect, исключения — собственная обвязка репозитория.

Юридически комбинированная работа распространяется под **GPL-3.0** — см. [LICENSE](../LICENSE) и [NOTICE](../NOTICE).

Это **не** официальный продукт Amnezia VPN, VK или Cloudflare.

## Краткая памятка

```
AWDTT
├── A  → AmneziaWG     → быстро, напрямую
└── WDTT → TURN + RAW  → обход, когда прямого нет
     └── опционально WARP на VPS → скрыть IP сервера
```
