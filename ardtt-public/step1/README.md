# ARDTT — Amnezia & RAW Dial over TURN Tunnel

  <img src="docs/assets/ardtt-icon.png" alt="ARDTT" width="128" height="128" />

Публичный репозиторий **готовится к публикации**.

Скоро здесь появится:

- Android-клиент **ARDTT**
- Self-hosted сервер (Docker Compose на вашем VPS)
- Прямой путь **AmneziaWG 2.0** и резервный **RAW Dial via TURN**
