# Обзор ARDTT

**ARDTT** (Amnezia + RAW Dial via TURN) — self-hosted VPN: Android-клиент и сервер на вашем VPS.

## Для кого

- Нужен **личный** VPN на своём сервере, а не коммерческий сервис.
- Прямой UDP до VPS **иногда недоступен**, но проходят «белые» сервисы и звонки.
- Готовы один раз настроить VPS и импортировать профиль.

## Роли

| Роль | Что видит |
|------|-----------|
| **Пользователь** | Подключение, профили, исключения, оформление |
| **Администратор** | + деплой VPS по SSH, журналы, телеметрия, расширенные настройки |

Режим администратора: долгое удержание в настройках (ползунок разблокировки).

## Термины

| Термин | Значение |
|--------|----------|
| **Path A / Прямое** | AmneziaWG 2.0, UDP до VPS |
| **Path B / Обход** | RAW через TURN, WRAP-шифрование, без WG поверх TURN |
| **Профиль** | JSON с ключами, endpoint'ами direct и bypass |
| **host_id** | Числовой ID пользователя на сервере → IP `10.8.0.{id}` / `10.9.0.{id}` |
| **Call hash** | Идентификатор звонка VK; создаётся на телефоне, на сервер не отправляется |
| **Скрыть IP** | Egress через Cloudflare WARP на VPS, а не с IP сервера |
| **Доверенная Wi‑Fi** | Пауза туннеля в выбранных сетях |

## Типичный сценарий

1. **Сервер:** `docker compose up` на VPS или деплой из приложения.
2. **Пользователь:** `./scripts/create-user.sh alice` → JSON-профиль.
3. **Телефон:** импорт профиля → VK (создать звонок) → Подключить.
4. **Сеть:** приложение проверяет доступность direct; при необходимости — bypass.
5. **Опционально:** «Скрыть IP», исключения приложений, trusted Wi‑Fi.

## Path B (обход) кратко

```
Приложения → VPN TUN на телефоне
      → WRAP (как RTP-медиа)
      → TURN по TCP
      → VPS wdtt-server (-listen-raw)
      → интернет (или WARP)
```

- Дозвон по умолчанию: **vkcalls** (Звонок VK).
- Запасной: **legacy** (с капчей).
- VK нужен только чтобы **создать** звонок; дальше работа по hash локально.

## Что не является ARDTT

| Название | Что это |
|----------|---------|
| **WDTT** | WireGuard over TURN/DTLS ([amurcanov](https://github.com/amurcanov/proxy-turn-vk-android)) |
| **nonameVPN** | Раннее имя черновика репозитория |
| **Официальный Amnezia / VK / Cloudflare** | ARDTT — независимый проект |
